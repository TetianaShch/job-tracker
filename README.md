# Project Job-Tracker

це Chrome extension, який дозволяє зберегти відкриту в браузері вакансію і пізніше переглядати список збережених вакансій.

## Description

Сценарій користувача:
Користувач відкриває сторінку вакансії.
Натискає іконку extension у Chrome.
У невеликому popup-вікні бачить назву сторінки та її URL.
За бажанням додає назву компанії та коротку нотатку.
Натискає кнопку ʼSave vacancyʼ.
Вакансія зберігається локально у браузері.
Користувач може переглядати вакансії, змінювати їхній статус або видаляти.
